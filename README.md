⚡ No-Trace
Zero-Log, Direct Browser-to-Browser P2P File Transfer Engine
🌌 Overview
No-Trace is a high-performance, browser-based file-sharing application designed for absolute privacy and zero server overhead. By leveraging WebRTC peer-to-peer data channels, files fly directly from sender to receiver across local networks or the internet—touching no third-party cloud storage.

Built with a futuristic Quantum Tether design language, it combines kinetic 3D aesthetics with enterprise-grade resilience to handle unstable hostel or conference Wi-Fi networks effortlessly.

✨ Key Features
Zero-Log Architecture: Direct P2P connection; your data never passes through a centralized database.

Quantum Tether UI: Kinetic, immersive dark-mode interface featuring glowing energy nodes and active laser links.

Instant Room Pairing: Secure temporary room IDs and auto-generated QR codes for zero-friction mobile connectivity.

Burn-After-Reading (Auto-Sever): Optional privacy toggle that instantly destroys the connection the millisecond a transfer completes.

Ghost Reconnect Protocol: Automatically handles Wi-Fi drops by freezing byte counters and auto-resuming mid-transfer.

Multi-File Queueing: Drag and drop entire batches of files; the engine queues and pipelines them sequentially.

Receiver Authorization: Explicit accept/reject control prompts for incoming payloads.

Optimized RAM Management: Custom 256KB chunking with Ping-Pong flow control to support multi-gigabyte file transfers without browser crashes.

🛠️ Tech Stack
Frontend: HTML5, Vanilla JavaScript (ES6+), Custom CSS3 (Glassmorphism & Keyframe Animations)

Networking: WebRTC via PeerJS

Icons & Typography: Phosphor Icons & Google Fonts (Outfit)

🚀 Quick Start / Local Development
Clone the repository:

Bash
git clone [https://github.com/roshanuag/NoTrace.git](https://github.com/roshanuag/NoTrace.git)
cd NoTrace
Run locally:
Open index.html using a local development server like Live Server in VS Code.

Establish a Tether:

Open two browser tabs (or use your phone and laptop on the live URL).

Copy the 5-digit PIN from the sender view.

Input the PIN on the receiver view to engage the quantum link.

Drop any file onto the stage to stream it instantly!
